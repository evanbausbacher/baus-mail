# Domain Key Mapping

Do not commit real Resend API keys.

Use this file only as a local note template if needed:

```text
example.com <resend-api-key-for-example.com>
another-example.com <resend-api-key-for-another-example.com>
```

For public or shared environments, prefer documenting domains without secrets and store API keys only in the running BausMail instance.
